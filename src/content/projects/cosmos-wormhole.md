## 是什么

cosmos-wormhole 是[小宇宙](https://www.xiaoyuzhoufm.com/)播客 App 的非官方 Python SDK，已发布到 PyPI：

```sh
pip install cosmos-wormhole
```

完整用法和文档见 [cosmos-wormhole.sorosliu.xyz](https://cosmos-wormhole.sorosliu.xyz)。
